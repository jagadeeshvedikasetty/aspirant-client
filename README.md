Aspirant Quiz Platform

A full-stack quiz application developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js) that enables aspirants to practice subject-wise quizzes, track performance, and improve their preparation.

🚀 Live Demo

https://aspirant-client.vercel.app/

🛠️ Tech Stack

Frontend

- React.js
- HTML5
- CSS3
- JavaScript (ES6+)

Backend

- Node.js
- Express.js

Database

- MongoDB

Tools

- Git
- Postman
- VS Code

✨ Features

User Features

- User-friendly interface
- Subject-wise quizzes
- Dynamic question rendering
- Instant result generation
- Responsive design for desktop and mobile devices

Admin Features

- Add questions
- Update questions
- Delete questions
- Manage quiz content

📋 Functionalities

- Quiz participation
- Question management
- Result calculation
- Database integration
- API-based communication between frontend and backend

📂 Project Structure

client/

- React Frontend

server/

- Node.js & Express Backend

database/

- MongoDB Collections

🔧 Installation

Clone Repository

git clone https://github.com/jagadeeshvedikasetty/aspirant-quiz-platform.git

Install Dependencies

Frontend:
npm install

Backend:
npm install

Run Application

Frontend:
npm start

Backend:
npm start
